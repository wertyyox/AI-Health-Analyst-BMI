# AI Health Analyst — BMI Calculator

A lightweight desktop application built with Python that serves as a basic health data analyst. It calculates the Body Mass Index (BMI) based on World Health Organization (WHO) standards, provides personalized feedback, and collects dynamic session statistics to compute the group's average BMI.

## 🚀 Features
- **BMI Calculation:** Computes BMI with high precision using standard mathematical formulas.
- **Smart Feedback:** Automatically categorizes results into *Underweight*, *Normal weight*, or *Overweight* according to WHO guidelines.
- **Data Session Memory:** Uses Python lists to temporarily store calculated data "on the fly".
- **Group Analytics:** Dynamically calculates total users analyzed and the average BMI of the group during the session.
- **Modern GUI:** Built with a clean, modern dark-themed user interface using CustomTkinter.

## 🛠️ Tech Stack
- **Language:** Python
- **GUI Library:** CustomTkinter
- **Math/Stats:** Built-in Python functions (`sum`, `len`, `round`)
